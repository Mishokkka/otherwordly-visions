# Otherworldly Visions 1.0.7

Модуль для Foundry VTT v13 и Forbidden Lands 13.0.5. Он добавляет скрытые потусторонние токены, персонажей со статусом «Тронутый», автоматические и режиссёрские вспышки видений, прогрессивное раскрытие объектов, условия видимости, триггеры и локальные настройки безопасности игроков.

## Установка

Поместите каталог `otherworldly-visions` в `Data/modules`, активируйте модуль в мире и перезагрузите Foundry. `libWrapper` рекомендуется, но не обязателен. Без него используется включаемый и полностью восстанавливаемый резервный патч `Token#isVisible`.

При первом запуске мастер-лидер автоматически переносит данные версии 0.7.5. Перед изменением создаётся резервная копия старых наборов и флагов Actor/Token. Копию можно экспортировать или восстановить в разделе «Диагностика».

## Основные возможности

- Статус «Тронутый» на Actor: ранг, теги, назначенные наборы и индивидуальные стадии раскрытия.
- Флаг «Потусторонний» на Token: требования, дистанция, LOS, темнота, Regions, свойства Actor, время на сцене и зависимость от показанного набора.
- Стадии 0–5: от полного сокрытия до полноценного проявления. Стадия 3 работает как периодическое мерцание.
- Подавление света, зрения, интерактивности и записи в трекере боя для невидимого токена.
- Vision Director с очередью, приоритетами, заменой/отбрасыванием, обратным отсчётом, повтором и аварийной остановкой.
- Взвешенный shuffle без повторов, cooldown записей и наборов, лимит на сессию.
- Связанные image/audio entries и кинематографические sequences.
- Автоматические триггеры сцены, боя, хода, движения, Regions, приближения, темноты, Actor/ChatMessage и событий Forbidden Lands.
- Массовый импорт файлов, рекурсивный обход папок, drag-and-drop, переписывание префиксов, bounded media cache и Asset Doctor.
- Игроки независимо ограничивают громкость, прозрачность, движение, фоточувствительное содержимое, скрытые вкладки и минимальную частоту.
- Диагностика транспорта, планировщика, кэша, ссылок, миграции и журнала команд.

## Открытие

Мастер открывает менеджер кнопкой глаза в группе Journal Notes на левой панели Scene Controls, через Configure Settings или макросом:

```js
game.modules.get("otherworldly-visions").api.openManager();
```

Редактор Тронутого доступен из заголовка Actor Sheet. ЛКМ на кнопке глаза в Token HUD переключает флаг, ПКМ открывает полный редактор токена.

Игрок открывает локальные настройки через Configure Settings → Vision safety. Горячая клавиша `Shift+M` переключает аварийное отключение.

## Безопасность сети

Модуль не доверяет обычным `game.socket` сообщениям. Удалённая команда записывается мастером в world setting и принимается только при валидном GM issuer, адресате, TTL, уникальном ID и допустимой частоте. Мутации world/Actor/Token в публичном API проверяют роль GM.

## Ограничения проверки

Архив проходит Node syntax/static/unit tests и проверку структуры ZIP. Полный интеграционный прогон Canvas, PIXI, ApplicationV2 и многопользовательской синхронизации должен выполняться внутри реального мира Foundry VTT v13.351.

## Audio sources and lifetime

Each vision set can draw audio from standalone files and any number of Foundry playlists. Every sound inside a selected playlist joins the randomized pool. Audio is intentionally independent from flash duration and plays to its natural end. Use Director → Stop All for an explicit emergency stop.
